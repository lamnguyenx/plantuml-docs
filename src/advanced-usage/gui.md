## Using the GUI

- Listing Files : Upon launching, the GUI lists all images generated by PlantUML from the monitored directory.

- Viewing Diagrams : To view a specific diagram, double-click its title within the GUI. Should you modify the source file of this diagram, the displayed image will refresh to showcase the changes.

- Auto-Update : Any edits made to monitored files within the directory trigger an automatic refresh of the corresponding image.

- Minimize/Iconify : If you need to work without distractions, minimize the GUI window as you work on your diagrams.
